# Custom Rust Web Shop Interface
Кастомное графическое оформление и скрипты автоматизации для авто-донат витрин игровых серверов Rust.

## 🛠 Технический стек проекта
* **Frontend:** CSS3 (Анимации, Flexbox, CSS Variables, Backdrop-filter blur)
* **Скрипты:** Vanilla JavaScript (ES6), DOM Events, CustomEvent API
* **Разметка:** HTML5 / AngularJS совместимая структура виджетов

## 🗂 Структура репозитория
* `style.css` — Кастомная тема интерфейса (прозрачные панели, адаптивная сетка, анимированные градиентные плашки цен и скидок).
* `script.js` — Системный конфигуратор магазина и модуль комплексной защиты контента витрины от копирования.
* `widgets.html` — Набор HTML-компонентов (социальные сети, блоки лояльности Steam, кастомные контейнеры описания услуг).

## 🔥 Реализованный функционал и особенности

### 1. Визуальный стиль и UX-дизайн
* **Glassmorphism:** Использование `backdrop-filter: blur(75px)` в сочетании с полупрозрачным фоном для создания современного эффекта матового стекла у карточек товаров и модальных окон.
* **Анимированные акценты:** Интеграция плавных бесконечных градиентов (`@keyframes gradient`) для динамической подсветки цен, скидок и количества предметов в рулетке.
* **Микро-взаимодействия:** Плавное масштабирование карточек товаров при наведении (`transform: scale(1.05)`) с аппаратным ускорением.

### 2. Защита интеллектуальной собственности
В файл `script.js` встроен жесткий модуль защиты витрины от несанкционированного копирования (рипа) дизайна конкурентами. Блокируются следующие действия пользователей:
* Вызов контекстного меню (`oncontextmenu`, `ontextmenu`).
* Выделение текстового контента (`onselectstart`).
* Копирование в буфер обмена (`oncopy`).
* Перетаскивание элементов интерфейса и картинок (`ondragstart`).
* Выделение мышью (`onmouseup`, `onmousemove`).

### 3. Автоматизация отображения цен
Реализован автоматический перехват загрузки элементов интерфейса. Скрипт сканирует все ценники (`.Product-module__price`) и при обнаружении стоимости `0` динамически подменяет цифровое значение на привлекательный текстовый маркер `БЕСПЛАТНО`.

## ⚙️ Инструкция по кастомизации под свой проект

### Настройка социальных сетей (`widgets.html`)
Найдите строки с тегами `<a>` для Discord и ВКонтакте и замените знак `#` на прямые ссылки на ваши сообщества:
```html
<a href="ВСТАВЬТЕ_ССЫЛКУ_НА_ВАШ_DISCORD" target="_blank" class="discord">
<a href="ВСТАВЬТЕ_ССЫЛКУ_НА_ВАШ_ПАБЛИК_ВК" target="_blank" class="vk">
```

### Настройка тега лояльности (`widgets.html`)
Измените текстовое поле, чтобы указать префикс, который игроки должны установить в свой никнейм Steam для получения бонусов на вашей витрине:
```html
<span class="bonus-title">NICKNAME | ТЕГ_ВАШЕГО_ПРОЕКТА</span>
```
